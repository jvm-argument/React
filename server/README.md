# React Server build

Специальная сборка основного античита для тестового сервера. Устанавливается **вместо** обычного Paper JAR, а не одновременно с ним. Название плагина и папка данных остаются `React`; DataCollector и другие существующие addons загружаются обычным образом. Обычная сборка `paper` не содержит команд выбора модели.

Сборка: `gradlew.bat :server:test :server:shadowJar`. Файл: `server/build/libs/React-Server-2.0.jar`.

Дополнительные команды:

- `/react model` — текущая выбранная модель.
- `/react model flower baseline`
- `/react model flower ultra`
- `/react model universe beta`

Требуется `react.server.model` (по умолчанию OP). Backend независимо проверяет право ключа на выбор всех моделей. Один ключ подписки в `plugins/React/inference.yml → auth.value` используется и для inference, и для управления моделью. Отдельный ключ ReactAuth для переключения не нужен. Никому не раскрывайте ключ в игровых сообщениях.

Переключение выполняется вне основного потока: GET `/api/v1/subscriptions/model` запоминает исходную модель, POST `/api/v1/subscriptions/model/select` меняет выбранную модель, затем атомарно сохраняется **корневой** `plugins/React/inference.yml`, обновляются family, name, URL и React перезагружается через существующий API. После перезапуска выбор сохраняется. Параллельные переключения отклоняются. При ошибке выполняется откат backend и локального файла; если подтверждение отката невозможно, React отключается до проверки администратором, чтобы исключить работу с несогласованными настройками.

До POST выбора старый `InferenceServer` переводится на паузу: новые запросы не отправляются, незавершённые запросы отменяются, устаревшие результаты отбрасываются. После успешной перезагрузки работает новый экземпляр, старый окончательно закрыт. Даже если запрос был отклонён до изменения локального файла, после подтверждённого отката выполняется reload прежней конфигурации: это сбрасывает ожидание старых запросов и поколения обработчиков игроков. Старый экземпляр не возобновляется. Если восстановительный reload не удался, React отключается до проверки администратором.

Базовый URL берётся только из доверенного локального `inference.endpoint.base-url`; HTTPS поддерживается штатно, HTTP допускается для частного/loopback адреса локального backend. Перенаправления отключены. Заголовок управления — `X-Subscription-Token`. Игрок не может указать URL или произвольное семейство/название.

Как и любая операция между отдельным backend и файловой системой Minecraft, переключение не является распределённой транзакцией: аварийное выключение ОС посреди запроса или недоступность backend во время отката требуют проверки выбранной модели после восстановления. Не запускайте параллельно ручное редактирование inference.yml и переключение модели командой.

Тесты проверяют whitelist профилей, сохранность остальных настроек и токена, атомарное сохранение и побайтовый откат, отказ при повреждённом YAML, реальный HTTP-контракт, правильный заголовок подписки, запрет публичного HTTP и перенаправлений.
